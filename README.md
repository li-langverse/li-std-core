# li-std-core

*Core standard library for Li — provable primitives for HPC, scientific computing, and AI (lip).*

## Build

```bash
lic build src/lib.li -o li-std-core
```

From the monorepo root, ensure `lic` is built: `./scripts/build.sh`.
